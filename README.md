# DataForge

> Schema-driven fake data generator

基于 Schema 配置的数据生成平台。

支持：

- Faker 中文数据
- 手机号生成
- 身份证生成
- 银行卡生成
- 随机数据
- 枚举数据
- 序列数据
- 日期数据
- 唯一值生成
- 空值生成
- Web Worker 高性能生成
- 多格式导出


---

# 技术栈


## Frontend

- React 18
- Vite
- Ant Design
- Zustand
- XLSX


## Data Engine

- Faker
- Web Worker
- Schema Driver

支持：
